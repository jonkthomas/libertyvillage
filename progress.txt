## 2026-02-07 - US-002: Create image download helper script

**What I did:**
- Created `scripts/download-image.js` with two modes:
  - Single: `--url <url> --slug <slug>` downloads one image
  - Batch: `--batch <json_file>` processes array of {url, slug} objects
- Script follows redirects (up to 5 hops) with browser-like User-Agent
- Validates downloaded files using magic bytes (JPEG/PNG/WebP detection)
- Deletes invalid files (HTML masquerading as images)
- Auto-optimizes with sharp to 800x600 progressive JPEG at quality 80
- Tested: single download, batch download, HTML rejection, redirect following

**Learnings:**
- Unsplash direct URLs work well for testing: `https://images.unsplash.com/photo-XXXX?w=800`
- HTTP->HTTPS redirect following works correctly with the protocol detection logic
- Magic bytes check catches HTML error pages that many servers return
- sharp handles JPEG/PNG/WebP input and converts all to JPEG output seamlessly
